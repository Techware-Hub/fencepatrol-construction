# Fencepatrol & Construction — Landing Page

> *Damage Disappears, Beauty Appears.*

A polished, animated marketing landing page for **Fencepatrol & Construction** — a Long Island-based fencing, construction, remodeling, and landscaping company.

## Tech Stack

- **React 19** + **Vite**
- **Tailwind CSS v3** (custom brand palette)
- **Framer Motion** (scroll-linked + parallax animations)
- **React Router** (landing + locked service pages)
- **React Icons**

## Features

- Hero with parallax bg image, animated logo, slogan headline
- Animated stats counter strip + trust badges (replacing legacy marquee)
- 6 service cards routing to gated/teaser detail pages
- About + 12+ years badge + animated stats grid
- Parallax slogan section (split horizontal motion)
- 4-step process timeline
- Project gallery with hover reveal
- Testimonials, FAQ accordion
- Full contact form (frontend-only, demo)
- Mobile responsive + floating phone CTA
- Scroll progress bar, viewport reveals, hover shine
